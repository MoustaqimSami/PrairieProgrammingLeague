# PPL brand

The Prairie Programming League logo: a wheat wreath around a sunrise over prairie fields.
The sun's rays are rings of dots, a nod to dot-matrix screens and the code side of the league.

## Files

| File | Use it for |
| --- | --- |
| `ppl-logo-horizontal.svg` / `.png` | Default logo: headers, posters, slides on light backgrounds |
| `ppl-logo-horizontal-on-dark.svg` / `.png` | The same on dark backgrounds |
| `ppl-logo-stacked.svg` / `.png` (+ `-on-dark`) | Square-ish spaces: social avatars, flyers |
| `ppl-emblem.svg` / `.png` (+ `-on-dark`) | The emblem alone, when the name is already nearby |
| `ppl-mark.svg` / `.png` | Small sizes only: favicon, app icon. Drops the wreath so it stays legible |
| `og-image.png` | Link preview image (1200 × 630) |

SVGs are the originals and scale to any size; the text in them is converted to outlines, so
they look right without the font installed. PNGs have transparent backgrounds.

## Font

[Urbanist](https://fonts.google.com/specimen/Urbanist) (free, SIL Open Font License).
The wordmark uses weight 700; the "Alberta · Saskatchewan" line uses 600 with wide letter spacing.
